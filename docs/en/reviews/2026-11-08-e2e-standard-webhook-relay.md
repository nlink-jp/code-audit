## Deviations (for the record)

- Phase 4 verification ran in parallel with the hunting waves (SKILL.md puts
  it after them). Nothing in the books depends on the order, and the critic's
  reassignment rule (no reassignment while a unit's candidates are pending)
  benefits from early decisions.
- Hunters received their input as `agents/briefs/hunter-N.md`, generated by
  the parent from the ledger and the class files; re-verifiers likewise from
  `findings.json`. `ledger.py brief` has no hunter or reverifier role.

- recon-c/d and hunter-12 reported having no Glob or Grep (the Explore type's
  tools vary); hunter-8/9 and reverifier-4/8 self-reported one read-only

## Lessons → candidates for cut 7

| # | What happened | Proposed fix |
|---|---|---|
| E13 | a quick prior becomes `unlinked_prior` wholesale under standard (subsystem field) | `seed` matches prior records by surface × boundary × class when the prior's profile is quick |
| E14 | units a critic adds get `prior_status: none` although priors exist | `merge-critic` sets `new` when the run has priors |
| E15 | `brief` has no hunter or reverifier role | `brief hunter --agent` (assigned units plus class text), `brief reverifier --fingerprint` (record, units, logs; never the verifier's layers) |
| E16 | a critic returns `priority` as a string and a class reference with `%20` | the critic contract says "an integer" and "spelled as the heading reads" (the validator already refuses) |
| E17 | the report's replacement line says "each confirmed by another fresh verifier" even with 0 strengthened | vary the sentence when the strengthened count is 0 |
| E18 | 0.5 candidates per unit and 20% re-asks overestimate (measured 0.26 and 5%) | set 0.35 / 10% from the two runs (between quick run 1 and standard run 2) |
| E19 | verifying during the waves worked | SKILL.md allows verification between waves explicitly |
| E20 | the critic's brief is 110–130 KB at 37 units | keeping every check result is right, but a `brief critic --since-wave N` delta would scale further |

The verifiers and re-verifiers behaved as designed: of 9 candidates none was
confirmed, 7 were refused under severity.md "What is not a finding" (operator
self-impact, guessed deployment behaviour) and 2 name the one deployment fact
that decides. Run-1's five confirmed findings are fixed and standard found no
regression.
